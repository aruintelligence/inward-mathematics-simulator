# Inward Mathematics Simulator v1.0.0

This release establishes the first versioned public baseline of the Remembrance Calculus™ and Witness Geometry™ browser simulation.

## Included

- Identity-attractor visualization
- Remembrance-strength and external-shock controls
- Guardian projection and drift constraints
- Multi-observer agreement and outlier visualization
- Coherence, distortion, drift, phase-lock, and memory-state telemetry
- Dependency-free client-side implementation

## Run

Open `index.html` in a modern browser.

## Scope

This is an exploratory mathematical and visual model. Its variables are defined by the simulation and are not established physical, psychological, or consciousness measurements.
