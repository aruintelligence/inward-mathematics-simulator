See what one value does to your numbers.

Paste 3–40 numbers, separated by commas or spaces. Add a known target if you have one. The result shows what changes when the value farthest from the median is removed. Analysis runs in this browser. Creating a challenge link puts the selected values in its URL.

Finite values from −1,000,000 to 1,000,000; use a period for decimals. The examples are invented. Do not treat a removed value as invalid simply because it is far from the median.

Turn these values into a prediction challenge ↗

A challenge needs exactly five readings and a known target, each from 0 to 100 with at most four decimal places. Its URL contains those values and may appear in browser history or hosting logs. Use invented or public data only.

The mean is the sum divided by the number of observations. The median is the middle sorted value, or the average of the two middle values. “Farthest” means greatest absolute distance from the original median; ties use the first entered value. Removing a point is a counterfactual, not a recommendation to discard data. A target you enter is a reference you supplied, not one verified by this page.
